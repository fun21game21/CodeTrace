# Поддерживаемый Python v1

Runner использует **CPython 3.13.16**, обычную сборку с GIL без экспериментального
JIT. CodeTrace выполняет исходник один раз, сохраняет наблюдаемые события и затем
показывает готовую трассу. Исключение во время выполнения — интерактивный `input()`:
тот же Python-процесс ждёт одну строку и продолжает работу после ответа.

Поддержаны присваивания, условия, циклы, обычные функции, рекурсия, простые классы
и обработка исключений. Данные: `int`, `float`, `bool`, `str`, `None`, точные builtin
`list`, `tuple`, `dict`, `set`, точный `collections.deque` и простые instance attrs.
Alias-ссылки и циклы сохраняются; одинаковые по содержимому независимые объекты
не объединяются. Tuple может ссылаться на изменяемые объекты. Порядок dict/deque
сохраняется, set имеет служебный порядок отображения.

Разрешены импорты `math` и `collections`; из `collections` гарантированно поддержан
`deque`. Остальные импорты дают `UNSUPPORTED_FEATURE`. Внешние packages отсутствуют.

Не поддерживаются `yield`/generators, `async`/`await`, потоки и подпроцессы,
пользовательские `exec`/`eval`/`compile`, `breakpoint`, произвольный файловый `open`,
подмена tracing/потоков и низкоуровневые записи в дескрипторы. AST/import/builtins
ограничения определяют subset, а не самостоятельную защиту хоста.

Сериализатор не вызывает пользовательские `repr`, `str`, iterator, property или
`__eq__`. Functions/classes/modules, неподдержанные типы, subclasses контейнеров,
сложные descriptors/properties, `__slots__`, custom metaclass и нестандартный
object access отображаются как **opaque**. `print`/`input` могут вызывать обычные
преобразования текста, явно запрошенные самой программой.

Tree читает только записанные атрибуты **instance `__dict__`**: по умолчанию
`value`, `left`, `right` либо имена из config. Каждый узел должен явно задавать
все три поля; отсутствие ребёнка — `None`. Class attributes, inherited defaults
и вычисляемые fields не заменяют instance state. Tree отклоняет общий child и цикл,
хотя сами циклы остаются доступны в Variables. Graph принимает направленный
невзвешенный `dict[int | str, list[int | str]]`, без bool; queue — list/tuple/deque.

Целые записываются точной десятичной строкой, float — encoded строкой, включая
`nan`, `inf`, `-inf`, `-0.0`. Identity скаляров не моделируется. Bars используют
только безопасные конечные числа; иначе показываются cells с пояснением.

LINE показывает состояние **перед** исполнением строки. CALL уже содержит новый
frame; RETURN ещё содержит выходящий frame. `RETURN` с raw `None` не доказывает
успешный возврат `None`: UI показывает выход из функции. EXCEPTION может быть
впоследствии обработан; итог определяется Completion. При принудительном завершении
последнее наблюдение не выдаётся за точное финальное состояние.

Начальные лимиты: 100 000 событий вместе с RUN_END, 50 MiB trace, 1000 элементов
на контейнер, 1000 десятичных цифр int, 2000 достижимых объектов, 10 000 объектов
registry за Run, 128 frames, 64 KiB Console. Визуально показываются первые 200
элементов массива или до 200 узлов дерева/графа. Одновременная достижимость всех
максимумов не обещается. Полный список — [defaults](../contracts/defaults.json).

Активный бюджет — 10 секунд, включая tracing/serialization/IPC; ожидание input
не входит в него, но ограничено 120 секундами на запрос и 300 секундами жизни
контейнера. Registry удерживает объекты до конца Run: GC, weakref, `__del__` и время
освобождения объектов не входят в гарантии эквивалентности обычному Python.

Нормативный источник: [Architecture Specification §§1, 9–12, 18, 22](../Architecture_Specification_v1.0.md).
